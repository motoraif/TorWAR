Setup Instructions
Access Keys Setup (Recommended)
Step 1: Create IAM User in Bedrock Account

In your Bedrock-enabled AWS account, create a dedicated IAM user:

aws iam create-user --user-name TorWARTA-BedrockUser

User Name: TorWARTA-BedrockUser

Step 2: Attach Bedrock Permissions

Create and attach a policy with Bedrock permissions:

{ "Version": "2012-10-17", "Statement": [ { "Effect": "Allow", "Action": [ "bedrock:InvokeModel", "bedrock:InvokeModelWithResponseStream", "bedrock:ListFoundationModels" ], "Resource": "*" } ] }
Step 3: Generate Access Keys

Create access keys for the user:

aws iam create-access-key --user-name TorWARTA-BedrockUser

Save the Access Key ID and Secret Access Key securely.

Step 4: Configure TorWARTA

Use the form above with the Access Keys method:

  • Account ID: 12-digit ID of your Bedrock account
  • Access Key ID: From Step 3 (starts with AKIA)
  • Secret Access Key: From Step 3 (40 characters)
  • Region: us-east-1 (recommended)
Tip: You can get any account ID by running aws sts get-caller-identity while using that account's profile.
Cross-Account Role Setup
Step 1: Create IAM Role in beyon-marketplace

In your beyon-marketplace account (766188184180), create an IAM role with trust policy:

{ "Version": "2012-10-17", "Statement": [ { "Effect": "Allow", "Principal": { "AWS": "arn:aws:iam::466171249965:root" }, "Action": "sts:AssumeRole", "Condition": { "StringEquals": { "sts:ExternalId": "TorWARTA-Bedrock-Access" } } } ] }
Step 2: Attach Bedrock Permissions

Attach the same Bedrock policy as shown in the Access Keys method.

Step 3: Update beyon-money-payer Role

Add AssumeRole permission to your current role in account 466171249965.
