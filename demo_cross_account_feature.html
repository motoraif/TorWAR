🔗 Cross-Account Role Source Credentials Feature

Demonstration of the new functionality for IAM Cross-Account Role connections

📋 Feature Overview

When adding a new AWS connection with "IAM Cross-Account Role" authentication method, users can now:

  • Select from existing key-value connections as source credentials
  • Or enter credentials manually as before
  • The system automatically populates credentials from the selected connection

🎯 Implementation Details

1. New API Endpoint
GET /api/key-value-connections - Returns existing access key connections for the current user
2. Enhanced Frontend
  • Dropdown populated when "IAM Cross Account Role" is selected
  • Dynamic form behavior - manual fields hidden when using existing connection
  • JavaScript functions: loadKeyValueConnections(), handleSourceConnectionChange()
3. Backend Processing
  • Handles source_connection_id parameter
  • Copies credentials from existing connection when selected
  • Falls back to manual credentials if no connection selected

🔄 User Flow

Step 1: Select Authentication Method
Step 2: Choose Source Credentials

✅ Benefits

🔒 Security

Reuse existing secure connections without re-entering credentials

⚡ Efficiency

Quick setup of cross-account roles using existing connections

🎯 Flexibility

Option to use existing or enter new credentials as needed
