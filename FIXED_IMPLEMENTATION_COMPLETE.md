## 🎯 **How to Use (Updated Workflow):**

1. Go to Settings page
2. Click "Upload Credentials File" button
3. Select your ~/.aws/credentials file
4. See file preview with all profiles detected

### **Step 2: Import All Accounts**
1. Click "Import All Accounts" button
2. All profiles automatically imported to database
3. See success message with count of imported accounts

### **Step 3: Switch Between Accounts**
1. Use dropdown in dashboard navigation (top right)
2. Select any imported account
3. All features (WAR, TA, Reports) now use selected account

### **Step 4: Manage Accounts**
1. View all accounts in Settings page
2. Activate/deactivate accounts as needed
3. Delete unused accounts
